파일 다운로드

🚀 LunchPop_Launcher.exe 업데이트 관리 · 필수 ⬇ 🖨️ LunchPop_Master.exe 주문 수신 · 인쇄 · 필수 ⬇

설치 방법

1
두 파일을 같은 폴더에 저장합니다.
예) 바탕화면\런치팝\
2
LunchPop_Launcher.exe를 실행합니다.
(Master는 직접 실행하지 않아도 됩니다)
3
매장명과 프린터를 설정하면 완료입니다.
이후 PC 시작 시 자동으로 실행됩니다.
⚠ Windows 보안 경고가 뜨는 경우
"추가 정보" 클릭 → "실행" 버튼 클릭
